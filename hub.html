Vibecoding 时代 为什么需要这个枢纽

📋 什么是 Vibecoding

由 Andrej Karpathy 提出，指通过自然语言描述需求、由 AI 生成代码的开发范式。开发者从"写代码"转向"描述意图 + 审查代码"。

🎯 枢纽定位

一站式资源门户：从数据→模型→技术栈→编码工具→智能体→模板→API→实战，覆盖 AI 辅助开发全链路，减少上下文切换。

🔄 与 Kaggle 站的关系

现有 Kaggle 数据集站点（index.html）是枢纽的「数据集中心」子站，已上线 v2.14；其余子站随 v2.16 全部上线。

📋 版本路线

v2.15 英文内部测试 + 枢纽启动 → v2.16 产品首页 + 全子站上线（含实战案例）→ v3.0 深度收尾 → v4.0 部署。详见 版本规划。

🔐 安全约束

所有凭证（Kaggle API / GitHub PAT）存于 macOS 钥匙串，绝不入库；原始数据不入库；推送 GitHub 前需用户确认。

🌐 双语策略

中文为主、英文内部测试（?beta=en 访问）。英文版暂不前端展示，待内容完善后公开。
