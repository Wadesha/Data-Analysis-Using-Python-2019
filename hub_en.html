The Vibecoding Era why this hub exists

📋 What is Vibecoding

Coined by Andrej Karpathy, it is a development paradigm where you describe requirements in natural language and AI generates the code. Developers shift from "writing code" to "describing intent + reviewing code".

🎯 Hub Positioning

A one-stop resource portal: data → models → stacks → coding tools → agents → templates → APIs → playbook, covering the entire AI-assisted development lifecycle and reducing context switching.

🔄 Relationship with the Kaggle Site

The existing Kaggle dataset site (index.html) serves as the hub's "Datasets Hub" sub-site, live since v2.14; all other sub-sites went live with v2.16.

📋 Version Roadmap

v2.15 English internal beta + hub launch → v2.16 product homepage + all sub-sites live (incl. playbook) → v3.0 deep polish → v4.0 deployment. See Version Roadmap.

🔐 Security Constraints

All credentials (Kaggle API / GitHub PAT) live in the macOS Keychain, never in the repo; raw data never enters the repo; user confirmation is required before pushing to GitHub.

🌐 Bilingual Strategy

Chinese-first with an English internal beta (access via ?beta=en). The English version stays hidden from the frontend until the content is polished enough to go public.
