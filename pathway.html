4 条典型进阶路径 按你的角色和起点选一条，照着走

🌟

零基础入门者

目标：30 分钟内做出第一个能访问的网站
  1. 想法：照 实战案例①「个人作品集博客」定目标。
  2. 技术栈：选 Next.js + Vercel（零运维部署）。
  3. 编码：用 Cursor / Copilot 生成页面骨架。
  4. 模板：套 Next.js 全栈模板 起步。
  5. 上线：按 部署最佳实践 推 Vercel。
⏱ 预计 30–45 分钟 · 难度 ★☆☆
📊

数据科学 / ML

目标：用真实数据做一个可交互的分析产品
  1. 数据：从 数据集中心 选本地数据集（wine / iris / students）。
  2. 可视化：看 详情页「⑩ 数据可视化」 派生分布。
  3. 技术栈：pandas + Streamlit 做看板。
  4. 模板：用 数据管线模板。
  5. 实战：参考 实战案例③「交互数据看板」。
⏱ 预计 45 分钟–1 小时 · 难度 ★★☆
🤖

AI 应用开发者

目标：做一个 RAG 问答或自动化 Agent
  1. 模型：从 模型中心 选 LLM（OpenAI / Claude / Ollama 本地）。
  2. 编码：用 RAG + Prompt 模式 搭检索。
  3. 智能体：上 LangGraph / CrewAI 做多步编排。
  4. API：接 OpenAI + 向量库（Pinecone / Qdrant）。
  5. 模板+实战：RAG 模板 + 实战②③。
⏱ 预计 1–2 小时 · 难度 ★★★
🏗

全栈工程师

目标：生产级服务（前端 + API + 数据库 + 部署）
  1. 技术栈：React + FastAPI + PostgreSQL + Docker 组合。
  2. 模板：套 微服务 / API 服务模板。
  3. 编码：AI 辅助 + 代码审查 提速。
  4. API：接 Stripe（支付）/ Twilio（通信）。
  5. 上线：部署与成本控制 最佳实践。
⏱ 预计 2–4 小时 · 难度 ★★★

我只会说需求，不会写代码

走 🌟 入门者 或 📊 数据科学。先让 AI 生成骨架，你只做审查和描述。模板能省掉 80% 搭地基工作。

我有数据，想做个东西

走 📊 数据科学。先在本站 数据集中心 确认数据形态，再选 pandas/Streamlit 看板路线。

我想做"会思考"的产品

走 🤖 AI 应用。模型 → RAG → Agent → API 四步，智能体框架 页帮你选型。

我要做能赚钱的服务

走 🏗 全栈。重点在 支付/通信 API 与 部署成本控制，别让账单失控。

🤖 走「AI 应用」路径做 RAG 知识库

① 选模型：看 模型·企业 RAG 案例——BGE 本地 Embedding + Cohere Rerank + GPT-4o。

② 套模板：用 模板·文档问答案例 的 RAG 脚手架，只换数据源。

③ 接 API：按 API·知识库案例 接 Jina Reader + pgvector + Claude。

④ 写代码：用 AI 编码·RAG+Reflection 的 Prompt 模式降低幻觉。

解析：四个子站的案例板块在此串成一条线——你不再需要在工具间反复切换上下文。

📊 走「数据科学」路径做交互看板

① 取数据：从 数据集中心 选本地 wine/iris，看详情页「⑩ 可视化」派生分布。

② 选技术栈：参考 技术栈·实时看板案例，轻量版用 pandas + Streamlit。

③ 套模板：用 模板·ETL 案例 做清洗，再接 Streamlit 渲染。

④ 避坑：遵循 实战·常见陷阱：数据不入库、先小样再全量。

解析：数据型项目最短路径就是「本地数据集 + 轻量栈 + 看板模板」，30 分钟出活。
