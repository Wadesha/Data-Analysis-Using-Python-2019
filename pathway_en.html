4 Typical Pathways pick one by role and starting point, then follow it

🌟

Absolute Beginner

Goal: build your first accessible website within 30 minutes
  1. Idea: set your goal following Playbook case ① "Personal Portfolio Blog".
  2. Stack: pick Next.js + Vercel (zero-ops deployment).
  3. Coding: use Cursor / Copilot to generate the page skeleton.
  4. Templates: start from the Next.js full-stack template.
  5. Launch: push to Vercel per the deployment best practices.
⏱ ~30–45 min · difficulty ★☆☆
📊

Data Science / ML

Goal: build an interactive analytics product with real data
  1. Data: pick a local dataset from Datasets Hub (wine / iris / students).
  2. Visualization: see the detail page "⑩ Data Visualization" for derived distributions.
  3. Stack: pandas + Streamlit for the dashboard.
  4. Templates: use the data pipeline template.
  5. Playbook: follow Playbook case ③ "Interactive Data Dashboard".
⏱ ~45 min – 1 hr · difficulty ★★☆
🤖

AI App Developer

Goal: build a RAG Q&A or an automation agent
  1. Model: pick an LLM from Model Hub (OpenAI / Claude / local Ollama).
  2. Coding: build retrieval with RAG + prompt patterns.
  3. Agents: use LangGraph / CrewAI for multi-step orchestration.
  4. APIs: wire OpenAI + a vector DB (Pinecone / Qdrant).
  5. Templates + Playbook: RAG template + Playbook cases ②③.
⏱ ~1–2 hrs · difficulty ★★★
🏗

Full-Stack Engineer

Goal: production-grade service (frontend + API + database + deployment)
  1. Stack: the React + FastAPI + PostgreSQL + Docker combo.
  2. Templates: apply the microservice / API service template.
  3. Coding: speed up with AI assistance + code review.
  4. APIs: wire Stripe (payments) / Twilio (comms).
  5. Launch: deployment & cost-control best practices.
⏱ ~2–4 hrs · difficulty ★★★

How to Pick a Path match your situation — don't force it

I can describe requirements but can't code

Take 🌟 Beginner or 📊 Data Science. Let AI generate the skeleton; you only review and describe. Templates save 80% of the groundwork.

I have data and want to build something

Take 📊 Data Science. First confirm your data shape in our Datasets Hub, then choose the pandas/Streamlit dashboard route.

I want to build a product that "thinks"

Take 🤖 AI Apps. Four steps: model → RAG → agent → API; the Agent Frameworks page helps you choose.

I want to build a money-making service

Take 🏗 Full-Stack. Focus on payment/comms APIs and deployment cost control — don't let the bill run away.

Case Walkthroughs: Run a Path End to End follow along — don't just daydream

🤖 Building a RAG knowledge base on the "AI Apps" path

① Pick the model: see Models · Enterprise RAG case — BGE local embeddings + Cohere Rerank + GPT-4o.

② Apply a template: use the RAG scaffold from Templates · doc Q&A case, just swapping the data source.

③ Wire the APIs: per API · knowledge base case, connect Jina Reader + pgvector + Claude.

④ Write the code: use AI Coding · RAG+Reflection prompt patterns to reduce hallucination.

Analysis: the case sections of four sub-sites connect into one line here — no more context switching between tools.

📊 Building an interactive dashboard on the "Data Science" path

① Get the data: pick local wine/iris from Datasets Hub; see the detail page "⑩ Visualization" for derived distributions.

② Pick the stack: reference Tech Stacks · real-time dashboard case; for the lightweight version use pandas + Streamlit.

③ Apply a template: use Templates · ETL case for cleaning, then render with Streamlit.

④ Avoid pitfalls: follow Playbook · common pitfalls: no raw data in repo, sample first then full scale.

Analysis: the shortest path for data projects is "local dataset + lightweight stack + dashboard template" — done in 30 minutes.
