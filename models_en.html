Case Studies Real-world selection decisions & trade-offs

💬 Customer Service QA Bot Beginner

Scenario: An e-commerce site needs 24/7 automated answers for shipping / return questions, about 20K inquiries per day, including sensitive operations such as order lookups.

Selection: General questions go to Claude Haiku (cheap, 200K context), handling 80%; when user orders are involved, switch to Ollama + Llama 3.1 deployed locally so data never leaves the intranet.

Steps: ① Use Claude to write an FAQ extraction script ② Wire up Function Calling to query the order API ③ Route cost-sensitive traffic to Haiku and privacy-sensitive traffic locally — a "cost-aware router".

Analysis: Closed APIs have low latency but bill per token — at 20K inquiries/day the monthly cost stays manageable; fully local gives the best privacy but requires GPUs. Hybrid routing balances both — exactly the "cost-aware routing" pattern from AI Coding in practice.

📚 Enterprise RAG Knowledge Base Advanced

Scenario: Turn 50K internal documents into a Q&A knowledge base where answers must cite sources and never hallucinate.

Selection: BGE-large for local Embedding (data stays in-domain) + Cohere Rerank for second-stage re-ranking + GPT-4o for generation; vectors stored in pgvector.

Steps: ① Chunk documents (512 tokens) → embed with BGE into pgvector ② Recall Top-20 → Cohere reranks down to Top-5 ③ Build an "answer only from the context below" prompt so GPT-4o generates with citations.

Analysis: Single-stage vector recall is limited; adding a Reranker significantly improves answer relevance; a local Embedding model both saves money and satisfies compliance. API "Cohere" and Stacks "pgvector" come together here.

🖼 Multimodal Content Moderation Advanced

Scenario: A UGC platform must understand image and text together (user caption + image) to detect violations, with high peak QPS.

Selection: Regular image-text content goes to Gemini 2.0 Flash (cheap, 1M context, native multimodal); tricky long images / video frames fall back to GPT-4o.

Steps: ① Combine image + text into a single multimodal request ② Routing: short content → Gemini Flash, long context → Gemini Pro, disputed samples → GPT-4o plus a human review queue.

Analysis: Multimodal models natively support mixed image-text input, far simpler than a two-stage "OCR + LLM" pipeline; apply the difficulty-based routing idea from the deployment comparison and reserve expensive models for hard samples.
