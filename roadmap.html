实施方法 架构、内容优先级、安全渲染、质量保障

完整版见 迭代版本与实施方法.md。要点：

  • 纯静态、零依赖：HTML/CSS/JS 可离线打开；数据分层（catalog 元数据 / datasets_desc 真实描述 / local_rich 手写精选 / domain_templates 领域模板 / profiles EDA 画像）。
  • 内容优先级：LOCAL_RICH（手写精选）> DATASETS_DESC（Kaggle 官方真实描述）> DOMAIN_TEMPLATES（领域模板兜底）——根治模板套话。
  • 安全渲染：描述先全量转义再按白名单重建标签，危险协议替换为 #；长文（>2600 字）折叠。
  • 数据不入库：Kaggle API 仅校验元数据（凭证本地、gitignored）；原始数据按需 kaggle datasets download 拉取，规避 100MB / LFS / 版权限制。
  • 质量保障：Node 桩 DOM 校验三分支（本地 / 远程有描述 / 远程无描述）均九段、无 raw markdown、无空占位。
范围边界：全程坚持「网页不存储完整数据集」。原始 806MB 数据始终留本地， 由下载脚本按需获取；网站只承载元数据、统计与说明文档。 登录体系暂缓，互动页以模拟示例呈现。
